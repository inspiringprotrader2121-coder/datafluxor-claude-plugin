# DataFluxor plugin

Registers the hosted DataFluxor MCP server (`https://datafluxor.com/mcp`, OAuth sign-in to your own DataFluxor workspace) and adds the `seo-research` and `datafluxor-cli` skills. No code, API key or credential is bundled. Support: support@datafluxor.com. Privacy: https://datafluxor.com/privacy. Terms: https://datafluxor.com/terms.
