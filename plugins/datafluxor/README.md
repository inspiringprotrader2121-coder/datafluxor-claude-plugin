# DataFluxor plugin

This plugin connects Claude to the hosted DataFluxor MCP server at `https://datafluxor.com/mcp` and adds a skill for selecting SEO research tools and interpreting their results. Use it to inspect public page metadata, crawl a small site, compare supplied domains and keywords, or request Google SERP and autocomplete data.

Install the plugin, then run `/mcp` in Claude Code and authenticate with your own DataFluxor workspace. A paid DataFluxor plan with credits is required for tool calls. The server lists only the tools available to your workspace and states each call's credit cost. No local server, API key, password, or customer credential is bundled.

Setup and tool guidance: https://datafluxor.com/mcp-for-seo. Privacy: https://datafluxor.com/privacy. Terms: https://datafluxor.com/terms. Support: support@datafluxor.com.
